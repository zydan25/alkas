# ملاعب الكأس — Alkas Sports City Management

نظام Flask/Python متكامل لإدارة مدينة ملاعب، الحجوزات، العملاء، الموظفين، المحاسبة، البطولات، الصيانة، الإعلانات، الإشعارات والتحديثات الفورية.

## المبدأ
- Modular Monolith منظم وقابل للتوسع.
- PostgreSQL + SQLAlchemy + Flask-Migrate.
- واجهة عربية RTL وPWA.
- نظام حجز زمني يمنع التعارض ويدعم عدة ملاعب والحجز الكامل.
- محرك إعدادات ديناميكي للهوية والألوان والمظهر والمحتوى.
- Accounting double-entry منبعث من العمليات التجارية.
